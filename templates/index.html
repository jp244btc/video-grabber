Browser extension
To load it: open edge://extensions or chrome://extensions, turn on Developer mode, click Load unpacked, and pick this folder. Then come back to this page once and it pairs itself.
The extension pairs itself the moment this page loads, so these two boxes are only a manual fallback. The token stops any web page you happen to be visiting from driving this downloader behind your back, so treat it like a password and do not paste it anywhere else.
