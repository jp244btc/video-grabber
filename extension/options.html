Point the extension at the downloader running on this PC.

The token is what stops any web page you visit from quietly driving your downloader. Treat it like a password.

Where these come from

  1. Start the downloader by double-clicking run.bat.
  2. In the page that opens, expand Browser extension pairing at the bottom.
  3. Copy the server address and token from there into the boxes above.
